# Java OOP Exercises

This repository contains **50 structured Object-Oriented Programming (OOP) exercises in Java**, designed to help you **practice clean OOP design, reusable classes, and professional coding patterns**.  

Exercises cover:
- Numbers & Arithmetic  
- String Manipulation  
- Arrays & Loops  
- Logical & Conditional Thinking  
- Real-World Scenarios  

---

## 📂 Project Structure


**Class Overview:**

| Package / Class | Purpose |
|-----------------|---------|
| `utils/MathUtils` | Factorial, Prime check, Sum of digits, Swap, Greatest of three, etc. |
| `utils/StringUtils` | Reverse, Palindrome, Count vowels, Count uppercase letters, Initials, Remove spaces, etc. |
| `utils/ArrayUtils` | Largest/Smallest number, Sum of even, Reverse array, Count occurrences, Separate even/odd, etc. |
| `services/LogicService` | Leap year, Triangle type, Driving eligibility, Grade calculation, Loan eligibility, etc. |
| `services/RealWorldService` | Simple/Compound Interest, BMI, Checkout, Banking, Temperature conversions, Electricity bill, etc. |
| `demo/DemoService` | Demonstrates calling methods from all utils/services |
| `App.java` | Entry point to run DemoService |
